1. Présentation & Syntaxe

Les structures de contrôles itératives (ou répétitives) sont indispensables lorsque le traitement doit être répété un nombre connu de fois.

Algorithme
// Compteur avec pas p
Pour cpt de Vi à Vf Faire [Pas=p]
   // Traitement répété
Fin Pour
Python
# Compteur avec pas p
for cpt in range(Vi, Vf + 1, p):
    # Traitement répété
